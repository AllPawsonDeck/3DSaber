# 3DSaber

A native one-saber rhythm game for Nintendo 3DS, optimized for Old 3DS.

Built by **3DCreatorS**.

## Current hardware-test build

- Native Citro3D rendering
- One saber
- Touch-screen slicing
- Easy / Normal / Expert only
- Built-in songs only
- No Cinema mod
- No custom-song loader
- Old 3DS target: 268 MHz / 64 MB
- Uses the uploaded app icon
- Temporary safe flat HOME Menu banner while booting is being verified
- CSND startup temporarily disabled in this boot-first test
